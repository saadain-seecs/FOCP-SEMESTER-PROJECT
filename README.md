# FOCP-SEMESTER-PROJECT
1. Project Overview: The IBCC & All Boards Attestation and Verification Management System is a console-based application which is used for attestation and verification process of educational documents, digitally. It allows users to enter their credentials, verify the status, and submit the attestation requests. It is very useful for students, educational institutions, and administrative departments.
2. Purpose / Objective: 
The purpose of this project is to automate the manual attestation process of IBCC and other boards. Traditionally, students have to fill out the forms manually, submit it physically, and faces time delays. However, this application provides an error-free, structured, and easy to use digital interface which makes the attestation services very efficient.
3. Problem Statement:
In Pakistan, thousands of students apply for attestation and verification of their documents. The manual application services often lead to mismanagement, delays, missing records, and difficulty in verifying status. However, this application solves this problem by providing an automatic and structured verification and attestation management system.
4. Key Features:
1.	Allows the users to enter their credentials such as name, roll on, cnic, board and document type.
2.	Stores the attestation request details and generates a request ID.
3.	Allows the users to update and modify their attestation requests.
4.	Provides automatic status updates such as pending, in-process, verified or rejected.
5.	Displays all requests in a formatted table.
6.	Offers search functionality.
7.	Also includes validation to avoid errors.
8.	Generates a summary report of the completed and pending attestation slips.
5. Tools and Concepts Used: 
It uses multiple c++ concepts/tools such as: 
•	Variables and Datatypes for storing applicant’s and document’s details.
•	Arrays / Structures for maintaining multiple attestation records.
•	Loops for repeated data entry.
•	Conditional Statements for updating and checking status of the application.
•	Functions for modular design/programming and reusability.
•	Switch statements for menu choices
•	Input Validation for securing correct data formats.
•	Formatted console output for cleaner user interface.
6. Expected Outcome:
When the program is executed, the user will be able to submit, manage, and track their attestation and verification requests. The output will give a clear and formatted record of all the applicants’ attestation statuses. So, this will totally increase the accuracy and efficiency in the attestation services.
