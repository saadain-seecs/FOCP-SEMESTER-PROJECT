# FOCP Semester Project

## IBCC & All Boards Attestation and Verification Management System

### Project Overview
The **IBCC & All Boards Attestation and Verification Management System** is a console-based C++ application designed to digitize the attestation and verification process of educational documents.

The system allows users to:

- Enter their credentials
- Submit attestation requests
- Verify application status
- Track document processing progress

This application is useful for students, educational institutions, and administrative departments.

---

## Purpose / Objective

The purpose of this project is to automate the traditional attestation process of IBCC and educational boards.

Traditionally, students are required to:

- Fill out forms manually
- Submit documents physically
- Wait for lengthy processing periods

This application provides a structured, user-friendly, and efficient digital solution that reduces errors and improves processing efficiency.

---

## Problem Statement

In Pakistan, thousands of students apply for document attestation and verification every year.

Manual processing often results in:

- Delays in processing
- Mismanagement of records
- Missing documentation
- Difficulty in tracking application status

This system addresses these issues by providing an automated and organized platform for managing attestation requests.

---

## Key Features

### Applicant Management
- Enter applicant details:
  - Name
  - Roll Number
  - CNIC
  - Board Name
  - Document Type

### Request Handling
- Store attestation request records
- Generate unique Request IDs
- Update and modify existing requests

### Status Tracking
- Pending
- In Process
- Verified
- Rejected

### Search & Display
- Search requests efficiently
- Display all requests in a formatted table

### Validation
- Input validation to reduce errors
- Secure and structured data entry

### Reporting
- Generate summary reports
- Display completed and pending attestation requests
